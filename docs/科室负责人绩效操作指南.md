# 科室负责人绩效操作指南

> 适用对象：各科室负责人（科主任 / 护士长等）
> 适用系统：绩效管理系统（大连市皮肤病医院）
> 版本：v1.0｜更新日期：2026-11-23｜适用：大连市皮肤病医院 各科室负责人

---

## 一、您在这个系统里能做什么

作为科室负责人，您在系统中的权限集中在三件事：

| 序号 | 要做的事 | 对应菜单 |
|---|---|---|
| 1 | 查看并**核对**本科室的一次分配结果（本页只读，无需操作） | 科室绩效 → 科室核算表确认 |
| 2 | 手工填报本科室的**二次分配**额度/明细 | 科室绩效 → 科室二次分配额度填报 |
| 3 | 查看本科室**明细与结算总额**，用于核对与解释 | 绩效分析 → 科室绩效明细分析 / 科室结算总额分析 |

> 您**看不到**其他科室的数据；也**不能**修改一次分配结果（一次分配由绩效办统一核算）。

## 三、任务一：查看并核对「一次分配结果」

### 3.1 打开页面

菜单：**科室绩效 → 科室核算表确认**

### 3.2 查看内容

页面按「核算项目」列出本科室（及您被授权的核算单元）的一次分配结果，常见列：

| 列 | 含义 |
|---|---|
| 项目编码 / 项目名称 | 收费项目 |
| 核算项 | 该项目归属的核算口径（如“医疗服务项目执行积分”） |
| 单位数 | 该项目的数量 |
| 本月最终值 | 本月该项目的绩效金额 |

> 说明：本页面为固定表格，**不含环比、同比等对比列**；需要对比分析请使用「科室绩效明细分析」。


![图2 科室核算表确认 — 列表页（只核对，不点确认）](assets/perf-guide/19-confirm-list.png)


### 3.3 核对结果（本页无需任何确认操作）

- 本页**不需要**做“确认”“提交”等操作，也没有「确认」按钮，属正常；
- 页面数据仅供科室**内部核对参考**；
- 若发现金额或项目归属异常，请联系绩效办核实；
- 核对完成后可直接关闭页面，不影响后续流程；
- 为便于运维与问题追溯，系统的登录与操作行为会被日志记录。

### 3.4 有疑问怎么办

| 现象 | 处理方式 |
|---|---|
| 金额与预期不符 | 先用「趋势」看历史，再用「科室绩效明细分析」定位到具体项目 |
| 工作量明显偏低 | 核对 HIS 项目是否按科室正确归属（找绩效办） |
| 数据为空 | 确认期间是否正确；仍为空联系绩效办 |

## 四、任务二：填报「二次分配」

### 4.1 打开页面

菜单：**科室绩效 → 科室二次分配额度填报**

### 4.2 填报逻辑（概览）

```
一次分配结果（系统算出）
      ↓  作为本科室可分配总额度
二次分配（您手工填报：分到人 / 分到组）
      ↓  提交
绩效办审核 → 生成发放依据
```


![图3 科室二次分配额度填报 — 填报页](assets/perf-guide/22-filling-list.png)


### 4.3 操作步骤

1. 选择**核算账期**（默认上月）；
2. 页面显示本科室可分配额度（来自一次分配）；
3. 按人员录入分配金额 / 系数；
4. 保存为草稿 → 核对合计是否等于额度；
5. 确认无误后**提交**；
6. 提交后如需修改，走「二次分配调整上报」流程。


![图4 二次分配提交后的状态](assets/perf-guide/24-filling-drawer-submitted.png)


### 4.4 填报注意事项

| 注意点 | 说明 |
|---|---|
| **合计应与额度一致** | 不一致时可能无法提交，请先核对 |
| 提交后锁定 | 提交后不能直接改，需走调整流程 |
| 金额为 0 也要填 | 未参与分配的人员建议显式填 0，避免歧义 |
| 保存草稿 | 未填完可先保存，退出后数据保留 |

## 五、任务三：核对与解释（查看类）

| 菜单 | 用途 | 典型场景 |
|---|---|---|
| 绩效分析 → 科室绩效明细分析 | 按「核算项 × 项目」看本月/上月/上年同月、环比、同比 | 解释“为什么这个月少了” |

## 六、常见问题（FAQ）

| 问题 | 原因 / 处理 |
|---|---|
| 登录后看不到菜单 | 权限未配置，联系绩效办/信息科 |
| 找不到「科室绩效对比分析」 | 该页面不对科室负责人开放，属正常 |
| 期间选错导致看不到数据 | 期间默认上月，请确认账期 |
| 页面数据是上月的 | 当月数据需绩效办完成核算后才可见 |
| 数字与财务口径不一致 | 系统口径是“核算口径”，与财务结算口径可能不同，以绩效办解释为准 |
| 提交失败提示“不平” | 分配合计与额度不一致，调整后再提交 |
| 为什么没有「确认」「提交」按钮 | 本页为只读核对页，不需要您操作 |
| 忘记密码 | 联系信息科重置 |
| 初始密码是多少 | 默认 `abcd1234`，首次登录会强制修改 |
| 账号是什么 | 一般为您的 OA 工号，不确定可问信息科 |

## 七、名词解释

| 名词 | 含义 |
|---|---|
| 一次分配 | 系统按核算规则算出的科室级绩效额度 |
| 二次分配 | 科室内部把额度分到人的过程（手工填报） |
| 核算单元 | 绩效核算的最小单位（如“治疗科医生”“皮肤一病房护士”） |
| 核算账期 | 绩效归属的年月，如 2026-10 |
| 环比 / 同比 | 与上月比 / 与去年同月比 |
| RVU | 项目点数（相对价值单位），用于衡量项目技术难度 |

## 八、责任与纪律

1. 账号仅限本人使用，**不得转借**；
2. 二次分配涉及个人利益，填报前请与科室管理小组充分沟通；
3. 提交前务必核对合计与额度；
4. 系统会记录每次修改（操作日志 / 配置变更记录），请勿随意试填生产数据。
